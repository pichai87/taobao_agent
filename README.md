# 电商经营数据分析 Agent

面向 Java / Agent 工程学习的企业架构项目。沿用既定的模块化单体、StateGraph、
语义口径、受控查询、确定性归因、审计和评测思路；不是更换成一个聊天 Demo。

**当前交付：后端主链、本机控制台、百炼单/多 Agent 工具调用和需求验收表。不是已经完成生产验收的企业系统。**
完整实施状态与上线门槛见 [实施状态](docs/实施状态.md)。

## 先运行

需要 JDK 21+、Maven 3.9.11+。当前工作区已下载 Maven 到上级 .tools，脚本会自动找到，
没有修改系统环境变量。当前机器实际用 JDK 25 编译，目标字节码为 Java 21。

在本目录的 PowerShell 中执行：

```powershell
./scripts/build.ps1
./scripts/start.ps1
```

启动后打开 [网页控制台](http://127.0.0.1:8080/)，登录并点击“开始分析”。
不需要读终端 JSON，网页会展示连接检查、任务步骤、GMV 和 SQL 证据。
详细操作见 [网页验证与学习指南](docs/网页验证与学习指南.md)。
新增功能见 [模型工具调用与需求验收](docs/模型工具调用与需求验收.md)：网页输入百炼 Key、模型选择工具、逐项记录 28 个需求的实现/验证/返工情况。
多 Agent 角色、交接协议、对照实验与学习顺序见 [多Agent协作与对照验证](docs/多Agent协作与对照验证.md)。

需要脚本验证时，另开一个终端（可选）：

```powershell
./scripts/smoke.ps1
```

默认只监听 127.0.0.1:8080，使用本机 H2 文件数据库和 OFFLINE_RULES（离线规则）规划器。
第一次启动由 Flyway 自动建表、装入 2696 笔合成订单与 270 条流量数据。
本机学习账号 analyst，密码 local-learning-only。**禁止把默认密码和 local 配置用于公开部署。**

测试命令为 `mvn verify`。macOS/Linux 用 Maven 构建后执行：
`java -jar ecom-agent-bootstrap/target/ecom-agent-bootstrap-0.1.0-SNAPSHOT.jar`。

## 你现在能使用什么

- GMV 查询、指定日期对比、品类贡献拆分、七日趋势、品类排序、GMV 定义。
- Spring AI Alibaba StateGraph：离线模式运行六节点；多 Agent 模式运行意图、调度、校验、报告四个图节点，专家在调度节点内独立调用模型与交接。
- SQL 模板白名单、参数绑定、查询超时、行数限制、独立读库连接。
- 任务持久化、幂等提交、确认执行、取消；离线图支持进程中断后的手动恢复，模型工具循环需新建任务。
- HTTP 认证、CSRF、任务所有者隔离、REST、SSE 事件重放。
- 可选 Spring AI 模型意图分类适配器；没有配置密钥不会调用外部模型。
- 网页临时百炼配置：Key 内存 30 分钟过期。保留单 Agent 对照模式（8 轮模型/12 次工具请求），新增多 Agent 模式（全局 16 轮/24 次工具请求/6 次派发）。用户已展示单 Agent 真实调用轨迹；多 Agent 目前通过受控协议测试，真实供应商验收仍待完成。
- IntentAgent 意图识别、Supervisor 规则调度、Query/Analysis/Ops/Other 专家；分析专家没有直接查库工具，必须通过受校验的证据包获得数据。运维专家仅能查看自己的任务状态。
- 需求验收表：按原文架构列项，勾选、验证程度、返工备注、逐行保存和版本冲突检查；本地记录不随 Git 上传。
- 内置 HTML/CSS/JavaScript 控制台：登录、历史任务、确认、取消、恢复入口、步骤和报告。
  与后端一起打包，无需单独安装前端依赖；不是原计划 Vue/ECharts 控制台的全部实现。

日期以请求中的 date / compareDate 为准，不会暗中从一句话猜日期。
当前分析指标只接受 GMV；指标字典中其他指标是口径说明，不意味着已经支持对应的自由分析。
TOP_N 当前是三个品类的完整排序，不支持任意 N。
