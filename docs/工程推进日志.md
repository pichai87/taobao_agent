沿用原企业计划的多模块仓库，不新建替代性 Demo。

过程中修正：
- 任务所有者必须取自认证身份，不能相信请求中的 owner。
- 同一幂等键不同请求返回冲突。
- 取消后的状态不能被迟到的工作线程覆盖。
- 恢复时跳过持久化的已完成节点。
- 没有对比日时，不把当日 GMV 冒称“差额贡献”。
- 定义查询不虚构数值结果。
- 七日趋势不能把每日 UV 相加当作跨日去重人数。
- SQL null 或未审核模板均拒绝。

本次 39 项自动测试通过，真实 HTTP/SSE 冒烟通过。
MCP、Worker、前端只保留边界与待办，详见实施状态，不能计入已完成业务能力。

下次恢复开发时：

确认工作区改动，再执行 mvn verify。
