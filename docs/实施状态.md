# 实施状态

更新：2026-09-14。以实际代码与验证为准，不把规划项写成已完成。

## 已实现

11 个 Maven 子模块的边界、Java 21 编译目标、统一 Spring Boot 启动。
实际 StateGraph 六节点工作流，六类受限 GMV 分析，离线规则规划器。
可选模型分类适配器、严格意图枚举校验。
真实数据库查询、BigDecimal 计算、贡献加和校验、证据与 SQL 模板报告。
Flyway 表结构、90 天合成数据、MyBatis 指标字典。
数据库任务/检查点/事件/工具审计，重复提交约束、取消和确认执行。
单实例进程中断恢复、有界执行队列。
Spring Security Basic、CSRF、任务所有者隔离、REST/SSE。
构建/运行/冒烟脚本，自动测试，学习与接口文档。

## 写了实现，但仍有验证边界

MySQL 配置与独立只读账号方案：本机尚无 Docker，未完成真实 MySQL 权限验收。
模型适配：mock 响应测试，不是外部模型联调或准确率结果。
SSE：有实现；需要持续补齐断连、慢客户端、压力及浏览器联调。
Java 21：使用 release 21 编译；当前实测运行在 JDK 25，CI 中增加 Java 21 执行。
