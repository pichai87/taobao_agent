## 写了实现，但仍有验证边界

MySQL 配置与独立只读账号方案：本机尚无 Docker，未完成真实 MySQL 权限验收。
模型适配：用户已提供单 Agent 真实调用截图；多 Agent 通过模拟供应商决策与真实 H2 集成测试，仍待百炼端到端验收，不是准确率结论。
SSE：有实现；需要持续补齐断连、慢客户端、压力及浏览器联调。当前页面用 HTTP 轮询。
页面恢复按钮：后端恢复已自动测试，浏览器尚未做进程崩溃后恢复验收。
Java 21：使用 release 21 编译；当前实测运行在 JDK 25，CI 中增加 Java 21 执行。
